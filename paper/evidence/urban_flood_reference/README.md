# Urban flood reference maps

This pack compares a four-state radar detector with a matched darkening-only detector and, where acquisition and grid coincide, GeoWatch’s archived Sentinel-1 reference. It records where flood signatures appear in built-up areas, where independently observed wet or dry surfaces support those signatures, and where no conclusion is possible. Results describe development floods.

- [METHOD](METHOD.md) defines the labels, comparators, denominators and uncertainty.
- [EVIDENCE](EVIDENCE.md) explains how to read the generated tables and maps.
- [LIMITS](LIMITS.md) describes sensor dependence, acquisition timing and dry-date controls.
- [REPRODUCE](REPRODUCE.md) gives the rebuild command. [Model handoff](../../../experiments/urban_flood_ref/LOAD.md) documents the retraining layout and public bands.
