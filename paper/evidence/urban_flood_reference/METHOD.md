# Method

The analysis uses one incident window and orbit-matched pre-event and event radar acquisitions per eligible tile. The four-state map retains ambiguous and unobserved surfaces. The matched intensity-only comparator runs with identical geometry, observation support and dry criteria. It isolates the effect of adding urban evidence to this detector. A distinct historical comparator reproduces the old study’s saved VV-drop extents on their original grids. Historical comparisons require an identical pixel lattice, same post date and one compatible relative orbit/scene. Different pre-event baselines are documented in the historical receipts. Unmatched archives receive a reason in the results.

The extent, change and disagreement statistics use the exported 30 m lattice. The all-area and built-up strata are reported separately. Ocean, terrain exclusions and cells with disputed signatures can remain outside the confidently labelled domain. The urban mask uses a strict native-pixel majority at 30 m. Detailed 10 m states, method bits and per-pixel acquisition dates remain available. See [detector rules](../../../experiments/urban_flood_ref/DETECTOR.md) and [aggregation and format](../../../experiments/urban_flood_ref/LOAD.md).

Independent categorical references must use 1 for known wet, 0 for observed non-flooded and 255 for unknown. Polygon-only masks contribute positives unless a separate surveyed dry footprint exists. Each reference has its own dates, sensor lineage and observable footprint. Benchmark flooded-urban classes use the **all-area** row on their own class-specific rasters, so the model’s definition of “built” cannot remove benchmark positives from this denominator.

Recall divides detected reference positives by all reference positives, including positives on which the detector abstained. The false-alarm proportion divides flagged reference negatives by all reference negatives. Both also appear conditional on the detector providing a definite class. Agreement is reported only on jointly classified reference and detector pixels, alongside coverage, numerator, denominator and abstentions. Added wet cells are split into reference wet, dry and unknown. Code returns an empty statistic for a zero denominator.

Within each event, aligned 33 × 33 cell blocks span 990 m, approximately one kilometre on the 30 m grid. This groups contiguous streets and neighbouring pixels before resampling. For each ratio a seeded bootstrap draws the occupied blocks with replacement 2,000 times, recomputes the ratio of summed counts and reports the 2.5th and 97.5th percentiles. Paired recall gain uses the same blocks for both detectors. The block width is a pragmatic spatial scale; correlations may extend farther than a block. With fewer than two contributing blocks the interval is unavailable. Pixel counts across overlapping tiles or across multiple references to one incident must not be treated as independent replication.

Pre-event monitoring pairs use the same algorithm. Their wet share is the count of detected wet cells divided by observed cells, including ambiguous cells in this denominator. This is a candidate false-alarm burden. Establishing actual false positives requires independent evidence that those cells were dry on the paired acquisition date.
