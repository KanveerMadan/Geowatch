# Input sources and reuse

| Input | Attribution, use and source |
|---|---|
| Sentinel-1 IW GRD | European Union / ESA / Copernicus. Calibrated dB backscatter, incidence angle and orbit metadata under Copernicus Sentinel data terms. [Catalogue](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S1_GRD) |
| GHSL built surface R2023A | European Commission, Joint Research Centre, open with attribution. Nominal 100 m multi-epoch interpolated built surface. [Catalogue and reuse notice](https://developers.google.com/earth-engine/datasets/catalog/JRC_GHSL_P2023A_GHS_BUILT_S) |
| Global Surface Water 1.4 | European Commission JRC / Google, Copernicus. Occurrence ≥80% excludes permanent water. Use valid-observation count to distinguish no water seen from no historical support. [Catalogue](https://developers.google.com/earth-engine/datasets/catalog/JRC_GSW1_4_GlobalSurfaceWater) |
| SRTM elevation | NASA / USGS, public domain. 30 m terrain screens using slope and approximate radar range direction. Building shadows remain unresolved. [Catalogue](https://developers.google.com/earth-engine/datasets/catalog/USGS_SRTMGL1_003) |
| MCD12Q1.061 IGBP | NASA LP DAAC, MODIS Land Cover Type, no restrictions on subsequent use. Prior-year mapped grassland/barren only for stable-open dry proxy. 500 m support. [Catalogue](https://developers.google.com/earth-engine/datasets/catalog/MODIS_061_MCD12Q1) |
