# Development benchmark protocol, 2026-11-19

This experiment estimates mapped footprint gain and loss in square metres per 100 m cell between two independent SpaceNet 7 surveys. It evaluates local change over an observed interval. It cannot date construction, count new buildings, or establish an operational alert.

The first California site was already inspected while testing survey ingestion. It can only be used in development. All other labels and scores were unseen when these rules were recorded.

* Order public SpaceNet 7 training sites lexically. Start development selection at zero-based ranks 0, 20 and 40; start geographic holdout selection at ranks 10 and 50. For each slot, take the next unused eligible site in catalogue order, wrapping at the end. Keep sites ≥ 300 km apart using tile centres to avoid treating neighboring suburbs as geographically held out. This is an engineering sample of widely separated sites.
* Select development sites' earliest available identical-calendar-month pair exactly one year apart. For holdouts select the latest such pair. Use only pairs whose six required public files together occupy at most 12 MiB per site, and skip sites on source metadata grounds only. Publish all selected sites and months before fitting or reading their labels. Report actual temporal overlap.
* In each site use the predetermined central 20 × 20 square of 100 m UTM cells, snapped to the production grid. Restrict targets to cells with complete mapped coverage in both epochs, including unusable-data and alpha masks. Retain genuinely stable cells. Report total, survey-supported and jointly sensor-observed cell counts.
* Primary inputs are monthly before and after NDVI, MNDWI and NDBI and their differences, calculated from the production Sentinel-2 reader. Use the same acquisition track for both epochs per cell, preferring maximum weaker-epoch date count, then total, then lexical track as in GeoWatch comparison. Both epochs must contain at least one fully valid acquisition. Use bounded, sequential requests to a dedicated cache. Site location, survey footprints, building confidence and target labels are excluded from predictors.
* If the Sentinel-2 source cannot supply two development sites and at least one holdout within the bounded request, report that limitation. A separate Planet-only fallback uses before/after RGB means and differences within the production cells from the provided monthly mosaics. Imagery used to annotate the reference is shared in this fallback. It cannot demonstrate Sentinel-2 transfer or independent-sensor accuracy. A poor Sentinel-2 result does not trigger the fallback.
* Fit a separate scikit-learn histogram gradient boosting regressor per target, max_iter=100, max_leaf_nodes=15, min_samples_leaf=20, early_stopping=False, random_state=0, squared error. These fixed low-complexity development settings constrain model capacity on three source sites. Clip predicted areas to the physical interval [0,10000] m². Compare against zero change and the development-set median for each target. Report per-held-out-site mean absolute error, RMSE, signed bias and mean target. Equal-weight test sites for the cross-site summary. Report working data source and exclusions. Run the evaluation once; do not retune from held-out results.
