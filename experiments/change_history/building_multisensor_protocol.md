# Building change from radar and optical endpoint observations

Frozen before inspecting new test-site imagery, labels or model scores. The five previously seen optical-experiment sites enter development. Accra and Cairo-area sites add training geography. Four new geographic test areas near Mexico City, Rotterdam, Lusaka and Dhaka were chosen by location before retrieving survey content. No neighboring site enters development. The manifest binds exact geographic tile IDs and records asset byte counts and ETags. The old sites retain their original months. For each new site use its latest available same-calendar-month one-year pair. Sites, dates and methods stay fixed even if a modality has no usable observations. No thresholds are optimized.

- Train separate regressors for mapped building additions and removals (square metres). Use SpaceNet 7 manually mapped monthly Planet mosaic footprints and published tracked object IDs. Count footprints whose ID exists at only one endpoint. Exclude blocks that lack full surveyed coverage at either endpoint or intersect an ambiguously covered changed object. This estimand omits extensions, shrinking footprints and short-lived construction between endpoints. Apparent disappearance is an imperfect demolition proxy. Persistent ID mistakes can create errors in both directions. Planet imagery supplies reference survey support only.
- Centre a 2 km square study grid at each site. Combine four complete 100 m UTM cells into an aligned 200 m reporting block. This neighborhood-size evaluation uses square blocks. It does not assume administrative boundaries. Incomplete edge blocks are excluded geometrically. Study sites are held out as entire geographic areas, but historical date ranges overlap across sites.
- Earth Engine Sentinel-1 IW VV/VH (same platform/pass/relative orbit) and Sentinel-2 surface reflectance NDVI, MNDWI, NDBI (same relative orbit). For each index, use same-track median at both endpoint months and their difference. Use a cell observation only when its whole sampled support is observed. A mode needs features from all four subcells; no replacement of cloud gaps with zero.
- Compare radar-only, optical-only, combined-input and zero-change estimates. All three use development sites only and identical fixed model settings inherited from the previous experiment. Each trains on its own observed blocks. Metrics are evaluated on the same held-out blocks for direct comparisons; additionally show each mode beside zero on its available support, including radar-only coverage under optical gaps.
- Report per-site block and reference-positive counts, area MAE, signed bias, changed and unchanged stratum MAE; aggregate common-support MAE by giving each covered site equal weight. There is no numerical pass threshold, cause classification or alert gate. Four selected sites cannot estimate global accuracy. Report missing reference strata and recent-year validation gaps.
- Use local sensor and survey caches, one location per process, bounded source reads. Each remote source is fully public. SpaceNet 7 data are CC BY-SA 4.0; Sentinel data use Copernicus Sentinel terms. Reproduction uses the manifest and machine-readable artifact digests. No production changes.
