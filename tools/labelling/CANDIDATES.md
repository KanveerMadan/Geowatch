# Candidate sources and regeneration

From the Item 21 worktree, point the repository Python environment at a training or practice tile. Earth Engine uses the existing authenticated project. If needed, supply its existing project ID in `GEE_PROJECT_ID`. One invocation handles one tile. The fixed output is a new `prelabels.gpkg` beside its image. The source cache belongs outside the repository.

```sh
caffeinate -i env OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m tools.labelling.generate "$tile_dir"
```

The generator checks the registered footprint and split before reading pixels or issuing queries. A second run preserves an existing package and returns an error. Use an authorized private copy for experiments or a fresh recipient tile. Every output layer has its class, immutable candidate ID, upstream source and ID, release/version information, source-supplied confidence when available, and mandatory review flag. The GeoPackage dataset metadata contains the complete tile receipt, source statuses, dates, attributions, candidate counts and deduplication counts. An empty query has a separate status from a failed source.

## Candidate construction

- **Buildings.** Google Open Buildings v3 uses the branch's signed-off confidence cutoff of 0.70. Footprints from Microsoft's legacy satellite-derived Earth Engine collection and mapped OSM buildings can add objects. Review in that order, taking the higher Google confidence first. If at least half the smaller of two building outlines overlaps, keep the higher-priority candidate. This conservative suggestion rule can suppress real adjoining roofs or retain shifted outlines. Review the actual roof or base convention for that image. The Microsoft mirror and hand-mapped OSM supplement avoid downloading country-scale files. A missing Google or Microsoft footprint says nothing about what is on the ground. [Google Open Buildings v3 and CC BY 4.0 terms](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_Research_open-buildings_v3_polygons)
- **Roads and sealed areas.** Use a numeric OSM width in metres or feet first. Otherwise the repository road-width table uses motorway 12 m, trunk 10, primary 9, secondary 8, tertiary 7, residential/unclassified/living street 5, service 4, track/pedestrian 3, cycleway 2, and footway/path 1.5. Each centreline is buffered by half the width. Track/path/footway need an explicit sealed material. Explicit unsealed surfaces, covered ways or tunnels are skipped. Surface parking and area:highway outlines must be checked against the image for soil, roof cover and trees. Underground, multistorey and rooftop parking do not become paved candidates. Multipolygon water outlines preserve mapped islands. Land-use green polygons appear only as hints. OSM is a current snapshot and can disagree with the historical tile. The OSM bbox API returns ways touching the query by member nodes, which can miss large polygons encompassing a tile. Incomplete multipolygon relations are omitted and counted. The shared Overpass client provides a second endpoint path if the map request fails. [© OpenStreetMap contributors, ODbL](https://www.openstreetmap.org/copyright)
- **Microsoft attribution.** The actual provider queries the sat-io `MSBuildings` country collections. The mirror's own catalog documents a May 2022 release under ODbL, while Microsoft's current upstream distribution cites CDLA Permissive 2.0. The asset ID, update timestamp when published, and query date travel with each receipt. [Mirror metadata and notice](https://gee-community-catalog.org/projects/msbuildings/) · [Current Microsoft distribution](https://github.com/microsoft/GlobalMLBuildingFootprints)
- **Vegetation, water colour and shadow.** These eight images have red, green and blue bands. Work at up to 800 pixels on the long axis of a 200 m tile. RGB excess green proposes vegetation at a normalised contrast of at least 0.13 with green above red and blue by more than six byte levels. Smooth blue-green patches appear only as water hints. Dark patches are also hint-only; a person decides whether the underlying class can be identified. The method can confuse blue roofs and water, green roofs and vegetation, or dark water and shadow. Small four-connected components are filtered using a 4 m² suggestion floor for vegetation and darkness and 8 m² for water hints. These fixed thresholds reduce speckle in the review queue. They have **no effect on the minimum size Kanveer can label**. Guide v1.6 gives roof-cluster and gap conventions, and no universal polygon area minimum. Raw-image conditions and acquisition dates are retained from each tile's metadata.
- **Geometry.** Clip to the actual 200 m tile and snap candidate vertices to its original image pixel-edge lattice. Retain valid polygons of at least a native raster pixel. A person can trace smaller, complex or previously missed surfaces and can reject or edit any candidate.
