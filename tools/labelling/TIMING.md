# Timing the assisted trace

The formal Cape Town Stage 1 tile `EPSG32734_282400_6233800` has 184 label polygons and a recorded **approximately 60 minutes**, including one restart. The dense-informal Cape Town tile has 278 polygons and no recorded timing. Only the first is a numerical baseline.

1. Practise navigation, accept, edit, reject and draw on an unscored practice tile. Keep practice time separate.
2. For the first timed comparison use the preselected formal Karachi tile `EPSG32642_297600_2761800`. Use the full 200 m square, the original imagery, the same guide and the complete topology/provenance checks. Choose this tile before seeing its completion time. Record interruptions, the imagery date, image resolution, fabric and any changes in working conditions.
3. Press the timer when starting work, enter the labeller's name, and review candidates individually. Include tracing missed features, overlaps, gaps, shadow and final QC correction. Stop for long unrelated interruptions, restart on return, and stop at the end. Save and run **Mark tile done**. Record the timer's total and whether QC passed. A tile with outstanding errors is still in progress.
4. Report minutes saved as **60 − assisted minutes** and observed speed ratio as **60 / assisted minutes**. Include polygon count and the validator's per-class polygon and area provenance shares. A faster but incomplete trace is unsuitable for the comparison. Differences in city, image resolution and roof density can change the time independently of the tools. This first comparison is a pilot; repeat across other fabrics before estimating a typical speed-up.
5. For the guide §7 repeat, use a fresh imagery-only scratch project without suggestions, the original labels, or model outputs. When the same person repeats a tile, wait at least one week. Follow the approximately 15% blind repeat and end-of-campaign drift check. Assess polygon agreement and 10 m fraction errors using the original bars.
